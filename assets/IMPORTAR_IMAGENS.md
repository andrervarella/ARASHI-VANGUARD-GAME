## Procedimento recomendado
1. Baixar o ZIP na conversa.
2. Enviar o ZIP ao Claude/Codex, se tiver acesso aos arquivos locais, e pedir para extrair o diretório \`assets/\` com a hierarquia preservada; OU extrair no próprio dispositivo e fazer upload dos PNGs de forma individual via GitHub.
3. Não enviar o ZIP único de 43 MB para o GitHub público. Cada PNG tem cerca de 2–4 MB; manter os arquivos individuais é mais simples para Git e revisão.
4. Comparar os arquivos recebidos ao \`manifest.json\` do ZIP (caminhos, tamanho e SHA-256).
5. Nas imagens de referências aprovadas, preservar o arquivo original; nunca substituir por geração sem aprovação.
6. NÃO enviar fotos pessoais reais ou fotos originais de Luke ao repositório público automaticamente.
